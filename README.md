# 云海仙途 · 修仙升级页游

一款可以直接在浏览器打开的修仙放置升级游戏。点击打坐攒灵气，灵气化修为，修为圆满渡雷劫突破境界；斩妖兽换灵石，灵石参悟功法、炼制丹药。

## 运行

三种方式，任选一种：

1. **双击 `index.html`** —— 纯静态，不需要任何服务。`file://` 已实测：图片、待机动画、6 个音频、本地存档全部正常。
2. **双击 `启动游戏.bat`** —— 自动检查/启动本地服务，然后打开浏览器。
3. **命令行起服务**：`python -m http.server 8123 --directory "<本目录>"`，再访问 `http://127.0.0.1:8123/index.html`。

存档写在浏览器 `localStorage`（键名 `xiuxian-online-save-v1`），每 10 秒自动存一次，切到后台、关页面前也会存。切到后台还会暂停结算，回来按离线规则补（五成效率、上限 8 小时）。「洞天」页有手动存档和转世重修。

## 分享给其他人玩

- **发文件（最省事）**：把 `云海仙途-网页版.zip`（1.4 MB）或整个文件夹发给对方，解压后双击 `index.html` 就能离线玩，不需要装任何东西。
- **局域网 / 同一 Tailscale 网络**：双击 `局域网分享.bat`，它会打印可分享的地址（形如 `http://<本机IP>:8080/index.html`），对方手机或电脑浏览器直接打开。首次运行 Windows 可能弹防火墙提示，选「允许」。
- **公开上线**：整个目录是纯静态站点（无后端、无数据库），可以直接拖到 Netlify Drop、推到 GitHub 仓库开 Pages，或放进任意静态托管 / 对象存储。上传时保持目录结构即可。

每个人的存档都存在自己浏览器里，互相独立；换设备或换浏览器不会同步进度。

## 发布到 GitHub Pages

本目录本身就是站点根目录（`index.html` 在最外层），推到 GitHub 后开 Pages 就有公开网址。

```bash
# 在本目录执行
git init -b main
git add .
git commit -m "云海仙途 · 修仙升级页游"
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

接着在仓库页面 **Settings → Pages**：Source 选 `Deploy from a branch`，Branch 选 `main`、目录选 `/ (root)`，保存。等 1–2 分钟，公开网址是：

```
https://<你的用户名>.github.io/<仓库名>/
```

几个要点：

- 仓库要设为 **Public**，Pages 才对所有人可见（私有仓库用 Pages 需要付费计划）。
- 首次 `git push` 时 Git Credential Manager 会弹出浏览器让你登录 GitHub，登录一次以后就不再问。
- 手机浏览器直接访问上面那个网址就能玩，可以加到主屏当 App 用。
- 目录里已放好 `.nojekyll`，避免 Pages 的 Jekyll 处理干扰静态文件。

## 手机适配

- 采用整屏应用式布局：上方场景固定、中间内容区独立滚动、底部标签栏常驻，不再是整页滚动。
- 适配 iPhone 刘海与底部横条（`safe-area-inset`）、动态视口高度（`100dvh`）。
- 触屏优化：按钮禁用双击缩放与长按选中，点击有高亮反馈，打坐可直接连点。
- 小屏自动压缩：视口高度 ≤760px 时缩小场景、妖兽与立绘；≤640px 时进一步压缩并隐藏底部说明，把空间让给操作区。
- 实测机型（Chromium 移动模拟）：iPhone 12（390×664）、Galaxy S9+（320×658）、iPhone SE（320×568）三款均无横向溢出、标签栏常驻、可滚动区 227–231px。

## 玩法

- **打坐吐纳**：点主按钮或按空格键，获得灵气与修为。修为条满了自动进一层。
- **突破境界**：每境层数圆满后出现「突破 · 渡雷劫」按钮，成功进入下一大境界，失败损失 45% 修为。悟道功法和破障丹提高成功率。
- **斩妖历练**：点「御剑攻击」或点妖兽造成伤害，击杀得灵石与修为。参悟「心剑合一」后可开自动攻击。
- **功法**：聚灵阵（灵气/秒）、吐纳术（点击收益）、御剑术（剑意）、护身法阵（灵石/秒）、炼丹术（丹药打折）、悟道（突破成功率）、心剑合一（自动攻击）。
- **丹药**：聚气丹（立刻得 40 秒灵气）、破障丹（雷劫 +15%，最多叠三层）、凝神丹（60 秒灵气翻倍）。
- **日课**：每天 4 件任务（打坐 200 次、斩妖 30 只、升层 5 次、服丹 3 次），完成可领灵石与丹药，跨日自动刷新。
- **宗门**：在青云宗（灵气 +15%）、太虚剑派（剑意 +20%）、丹霞谷（炼丹 -15%）中择一。斩妖、升层、突破累积宗门贡献，贡献可换内门弟子→真传弟子→执法长老→一宗之主五个职位，每个职位再加护一层属性。
- **天榜**：20 位本地推演的修士与你按「道行」（累计修为）排行，对手随天数增长，你可以一路往上爬。
- **离线结算**：闭关期间按五成效率累计灵气和灵石，上限 8 小时，回来会弹结算窗。

境界一共十境：炼气、筑基、金丹、元婴、化神、炼虚、合体、大乘、渡劫、仙人。元婴境起背景与妖兽图会换成第二套美术。
